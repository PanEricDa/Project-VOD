# 五人小队：战场指挥玩法原型

用于验证“玩家拉怪与指挥、AI 承担职责、集中爆发后继续战斗”的独立 HTML 原型。仅使用 Canvas 几何体，无外部资源、无构建步骤、无网络依赖；不是 Godot 模拟精度验证，也不修改正式游戏。

## 启动

直接用桌面浏览器打开本目录 `index.html` 即可。推荐键盘鼠标，浏览器窗口宽度至少 1100 像素。

也可以在项目根目录运行：

```powershell
node Prototypes/TacticalSquad/serve.cjs
```

然后访问 `http://127.0.0.1:8765`。服务器仅监听本机；Ctrl+C 关闭。可给脚本传入其他端口。

## 操作

| 操作 | 功能 |
| --- | --- |
| WASD | 移动先锋 |
| Q | 180 像素范围内、视线可达的敌人获得 8000 临时仇恨，持续 5 秒；冷却 8 秒 |
| E | 在当前鼠标位置设定交战中心 |
| 右键地面 | 同样设定交战中心；爆发选择期间则取消爆发 |
| 点击“交战位置”按钮后单击 | 用鼠标部署交战中心 |
| F | 恢复以先锋为中心跟随 |
| 单击敌人 / 空地 | 标记 / 取消优先目标；仅改变输出角色的优先选择，不直接生成仇恨 |
| Tab 或“集中爆发” | 进入 0.08 倍速预览；单击区域确认，Esc 或右键取消 |
| Space | 暂停 / 继续；切走窗口也会自动暂停 |

## 已落地的内容

- 玩家先锋 + Guardian、Priest、Caster、Archer，严格五人。
- 坦克接怪与范围嘲讽：增加常规仇恨池数值，不锁定目标，不覆盖先锋限时贡献。仇恨按 14 秒半衰期衰减；切换目标需要超过当前目标 1.1 倍。
- Priest 自动低血治疗，低于 40% 时施放 150 点大治疗，15 秒冷却。
- Caster 普通小范围攻击与爆发范围结算；Archer 普通单体攻击与三连射。优先目标会影响 Archer 爆发选敌。
- 近战、驻守射程的远程、地面落雷施法者、强化周围敌人伤害的光环精英。
- 静态墙体阻挡移动、视线与投射物；AI 能绕路。
- 临时仇恨到期移除，敌人继续按剩余仇恨选择目标；挑衅不改变敌人的射程。
- 普通有效伤害与击杀恢复专注，无被动回满；爆发伤害及爆发击杀不返还专注。
- 爆发消耗 45 专注，16 秒冷却，135 像素落点半径。Caster 范围伤害 92，Archer 三次 66 点单体伤害。需满足输出角色射程、视线与存活条件；按命中时位置结算。
- 结束统计：用时、爆发次数与时刻、爆发击杀与伤害占比、阵地指令数、幸存队员。
- 先锋死亡后仍可指挥；所有具备攻击能力的队友死亡即失败，避免只剩无输出单位时卡局。

数值和“独立爆发冷却、战中专注恢复”均为本原型的试验假设，未视为正式设计决议。普通技能冷却与爆发入口独立，便于先验证宏观指挥，尚未模拟正式项目技能冷却争用。

## 三种试玩

1. **普通敌群**：6 名敌人。试着在集中后一次爆发完成大部分清理；再不爆发打一遍作比较。
2. **混合合波**：3 群、15 名敌人。可逐群推进，也可主动合并；优先处理施法者或光环精英，再观察集火和范围爆发的取舍。
3. **多轮战斗**：初始同上，第 48 秒在东侧增加 5 名援军。检验保留专注、转移位置与后续爆发。若提前清空首批，需等待明确倒计时结束；这段波间等待也是待评估的实验条件。

右侧敌人生命和爆发伤害倍率重开生效，固定布局便于重复比较。可先使用默认 1.0 倍，再把生命提高到 1.4 倍，观察多轮是否只是重复。

建议试玩时记录：

- 为什么在那个时刻爆发？是否是自己创造的机会？
- 爆发后有没有清楚的下一步目标？
- 移动交战点、切换优先目标是否确实改变结果？
- 第二次爆发是否处理不同问题，还是只等冷却？
- 常态输出是否过快，让准备失去意义；或过慢，让残局拖沓？

## 验证与限制

```powershell
node --test Prototypes/TacticalSquad/simulation.test.cjs
# 安装有 Playwright 与 Edge 时，先启动本机服务器：
node Prototypes/TacticalSquad/browser-test.cjs <playwright包目录>
```

模拟测试检查仇恨交接、射程不变、墙体路径、爆发范围和消耗、专注恢复、增援、胜负及整局运行；浏览器测试操作实际按钮和键盘，检查移动、拉怪、预览、取消、爆发、暂停、重开和设置。

`preview.png` 是浏览器测试生成的实际运行截图。

没有实现正式 Godot 导航、动画、装配、技能条件随机延迟、装备、完整资源经济、敌人脱战重置、救援复活或终结技。先锋在此版本不承担直接输出。原型测试通过只说明操作和流程可运行，不等于玩法或平衡已验证。

本目录 `.gdignore` 防止 Godot 导入原型及测试产物。
