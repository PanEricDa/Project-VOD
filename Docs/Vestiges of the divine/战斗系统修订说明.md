# 战斗系统修订说明

完整设计已合并至 [InitialGameSystem.md](InitialGameSystem.md)。本文仅保留本轮修订摘要。

## 核心修订

- 基础体验改为“玩家带领 AI 队伍移动并自动清怪”；拉怪、聚怪、定点和爆发属于主动介入后的增值体验。
- 专注系统保留 Tab、极慢速、技能顺序编排、追击槽和终结技。
- 一次爆发可编排约 4～5 个技能段。
- 技能连携采用相邻标签承接，不穷举完整技能排列。
- 不匹配时技能仍正常造成基础伤害，但没有连携增强、追击槽和终结判定。
- 每个技能都可以造成基础伤害，最后的爆发技能负责主要结算，不垄断伤害来源。

## 六种 SkillActionType

```text
GATHER       聚集
LAUNCH       浮空
CHAIN        连锁
SPREAD       扩散
ACCUMULATE   蓄能
RELEASE      爆发结算
```

技能自身类型、可承接类型和输出类型共用这一组 enum，不另设 `SkillTypeTag`。

当前爆发套路：

```text
聚集爆破：GATHER → RELEASE
空中叠伤：LAUNCH → LAUNCH → RELEASE
连锁爆破：CHAIN → CHAIN → RELEASE
扩散爆破：SPREAD → SPREAD → RELEASE
蓄能回响：ACCUMULATE → ACCUMULATE → RELEASE
```

“护盾反击”移出爆发套路，归入掩护系统；掩护不依赖敌人受击量产生不可控的反击伤害。

## Godot 结构

当前采用最简结构：

```text
SkillActionType.gd  # enum
SkillData.gd        # 技能 Resource
SkillSystem.gd      # 连携判断和六种动作方法
skills/*.tres       # 具体技能配置
```

暂不使用 `Behavior` 层、六个行为节点或六个独立脚本。未来只有当某个动作方法明显膨胀时再拆分。

## 与原文档的关系

原始设计中的世界、单位、地图、营地和奖励系统均保留。本轮主要修订了战斗系统中的：

1. 基础战斗定位；
2. 专注与爆发流程；
3. 连携标签结构；
4. 掩护与护盾反击的职责；
5. Godot 技能配置和执行结构。

原文中过期的数值、输入细节和旧协同标签方案已在 [InitialGameSystem.md](InitialGameSystem.md) 中使用删除线保留。
