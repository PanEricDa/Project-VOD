# 《神代遗痕》游戏设计文档

## 一、游戏概述

### 1.1 核心体验定义
玩家扮演一名**先锋**，带领四名AI队友，进入随机生成的遗迹副本，执行清扫委托。

~~核心循环：**拉怪→聚怪→定点→击杀**。~~

**当前修订：**基础体验是玩家带领队伍移动，AI自动清理敌人；拉怪、聚怪、定点和爆发属于玩家主动介入后获得的增值体验。玩家可以低操作推进，也可以通过路线、站位、技能顺序和追击操作获得更快、更强、更华丽的清场效果。

### 1.2 设计原则
- **单人操作，团队协作：** 玩家只操作先锋角色，AI队友自动战斗，但可通过战术暂停精确编排。
- **操作极简，策略深厚：** 核心操作不超过5个键，但职业构筑、路线规划、专注分配、技能序列编排提供丰富决策空间。
- **逐步解锁，平滑成长：** 系统随主线进度逐一解锁，避免初期信息过载。
- **高重玩价值：** 词缀、环境随机、职业构筑差异，确保每次副本体验不同。

### 1.3 世界观简述
西方奇幻背景，神明战争后遗留大量危险遗迹。玩家隶属于“圣物回收与深渊清扫工会”，是负责处理这些烂摊子的小队先锋。不是天选勇者，而是拿钱干活的专业人士。叙事基调：正统西幻中夹杂一丝克制的“打工”共鸣。

## 二、五大系统框架

### 2.1 战斗系统（核心体验层）
玩家在副本中的所有即时操作和战术决策。

#### 2.1.1 基本流程
~~拉怪 → 聚怪 → 定点 → 击杀~~

**当前修订：**

```text
移动探索 → 接触敌人 → AI自动战斗 → 玩家调整位置或介入爆发 → 继续前进
```

“拉怪—聚怪—定点—击杀”仍然是高阶战斗的重要支柱，但不再是每场战斗都必须完成的固定流程。


#### 2.1.2 拉怪
**基础形态：** 先锋使用职业专属开怪技能（如战地先锋的“咆哮”），使怪物进入追击状态。怪物会以略低于玩家的速度追赶。

**操作：** 移动（WASD）+ 开怪技能（右键）+ 闪避（Shift）。

**已讨论设计：**
- 职业差异化拉怪方式：战地先锋（近身咆哮）、暗影行者（远程印记）、秘术师（放置诱饵）、游荡弩手（箭雨陷阱）。
- 装备/遗物可改变拉怪行为：附加拉拽、连锁标记、诱饵自动行走等。
- 环境物件辅助拉怪：攻击回音水晶触发范围挑衅、粘液池减速追兵。

**待设计项：**
- 各职业开怪技能的详细参数（范围、冷却、资源消耗、激怒/注视叠层机制）
- 怪物追击的具体行为规则（追击时间、丢失仇恨条件、脱战逻辑）
- 拉怪过程中的玩家状态UI提示（注视层数/激怒等级/血量预警）

#### 2.1.3 聚怪
**基础形态：** 玩家带着追击的怪物跑向预设杀戮点，怪物自然聚拢。

**操作：** 移动走位，可利用环境物件（窄口、粘液池）。

**已讨论设计：**
- 环境物件辅助聚怪：窄口强制压缩、坍塌石柱封路、升降平台集中
- 队友自动掩护间接协助聚怪（坦克击退散怪、输出减速区域）
- 主动呼叫掩护（Ctrl键）可瞬间获得强控场，帮助聚怪
- 装备/遗物可能赋予聚怪新手段（挑衅附带拉拽效果）

**待设计项：**
- 环境物件的生成规则和在房间中的分布逻辑
- 怪物被聚拢后的队形变化和碰撞体积处理
- 聚怪完成度的视觉/音效反馈（如怪物集中度提示）

#### 2.1.4 定点
**基础形态：** 玩家跑到队友附近或某个环境物件旁停下，确定为杀戮点。

**操作：** 停止移动，可按下“攻击”指令（可选）让队友接战。

**已讨论设计：**
- 定点位置策略：选择开阔地、爆炸桶旁、窄口出口、高台等
- 队友会预先占据有利位置（远程上高地，坦克在你侧前方）
- 遗物可能提供定点后临时增益（定点后获得护盾）
- 战术暂停前通常需要在定点位置确认开战

**待设计项：**
- 定点的UI提示（队友位置标记、环境物件高亮）
- 队友接战的具体条件（玩家停下多久？是否必须按指令？）

#### 2.1.5 击杀（基础）
**基础形态：** 队友AI自动攻击，玩家可操作先锋参与输出或使用终结技。

**操作：** 普通攻击（左键）、先锋自身技能（如可用）、终结技（长按空格）。

**已讨论设计：**
- 队友AI逻辑：坦克嘲讽并保护脆皮，输出优先打低血量，治疗抬血
- 先锋在击杀阶段主要为处决精英/补刀，并准备释放终结技
- 环境物件可被技能引爆，增加AOE伤害

**待设计项：**
- 先锋在击杀阶段的详细操作（普攻连招、技能参与、走位要求）
- 队友AI的击杀优先级具体规则（如何处理多目标时的选择）

#### 2.1.6 爆发系统（专注编排+追击+终结技）

爆发是普通 AI 清怪之上的高阶操作，不是每场战斗的必需流程。

**当前设计：**

- 专注点上限暂定为100，具体恢复和消耗数值待定；
- 按下 Tab 进入专注状态，游戏进入极慢速；
- 玩家选择约4～5个队友技能的释放顺序后确认执行；
- AI按照顺序释放技能；
- 技能之间出现追击槽，玩家可按空格强化下一段技能；
- 追击失败不取消技能，只失去追击强化，并可能中断当前连携；
- 完成有效连携并满足条件后，可按空格进入终结技；
- 终结技拥有独立的高伤害和专属演出。

**连携规则：**

每个技能配置 `action_type`、`accepted_types` 和 `output_type`。下一个技能能否承接，只判断上一个技能的输出类型是否被当前技能接受。

```text
匹配：基础效果 + 连携增强 + 追击槽
不匹配：基础效果，无连携增强，无追击槽，不进入终结判定
```

当前不另外建立 `SkillTypeTag`，技能类型和连携标签共用同一组 `SkillActionType`：

```text
GATHER       聚集
LAUNCH       浮空
CHAIN        连锁
SPREAD       扩散
ACCUMULATE   蓄能
RELEASE      爆发结算
```

六种类型的底层共性是：空间位移、目标转移、数值蓄积和数值结算。

**当前爆发套路：**

```text
聚集爆破：GATHER → RELEASE
空中叠伤：LAUNCH → LAUNCH → RELEASE
连锁爆破：CHAIN → CHAIN → RELEASE
扩散爆破：SPREAD → SPREAD → RELEASE
蓄能回响：ACCUMULATE → ACCUMULATE → RELEASE
```

每个技能都可以造成基础伤害，伤害可以分布在起势、延续、转化和收束阶段，不是只有最后的 `RELEASE` 技能才造成伤害。

**实现方向：**

- `SkillActionType.gd`：定义六个 enum 值；
- `SkillData.gd`：定义技能 Resource；
- `SkillSystem.gd`：统一判断连携并执行六种动作；
- 每个具体技能使用一个 `.tres` 配置文件；
- 当前不使用 `Behavior` 作为角色行为或技能类型名称，也不要求六个独立脚本或六个场景子节点；
- 未来只有当某个动作方法过于庞大时，才将其拆成独立脚本。

#### 2.1.7 掩护系统
在拉怪、聚怪和移动过程中使用的保障手段。掩护和爆发共用“进入专注—选择技能—确认”的基础操作，但掩护不进入追击和终结流程。

**当前设计：**

- 掩护主要保护玩家和 AI 队友；
- 主要价值是防止技能被打断、稳定站位、帮助队伍通过危险区域；
- 护盾不依赖敌人必须攻击，也不根据不可控的受伤量决定最终爆发伤害；
- 可以保留固定的护盾、减伤、嘲讽、诱饵、减速和治疗等效果；
- 自动掩护是否保留，以及其触发条件，继续单独设计。

#### 2.1.8 专注系统（战略资源）

专注主要服务于：

- 爆发编排；
- 掩护行动；
- 后续可能加入的非战斗用途。

### 2.1.9 当前战斗系统归纳

```text
AI自动清怪是基础体验
玩家规划位置是增值体验
专注系统是低频战术介入
SkillActionType是有限连携语言
SkillData.tres是技能配置
SkillSystem.gd是统一执行入口
```

### 2.2 单位系统（角色与敌人）
所有可操作、可成长的友方和敌方角色。

#### 2.2.1 先锋（玩家角色）
**职业：** 战地先锋、暗影行者、秘术师、游荡弩手（首发4个）。

**成长：** 职业等级1-10。
- 1-4级：快速解锁基础技能
- 5级：终结技强化
- 7级：职业专属被动
- 9级：第二装备槽
- 10级：终结技终极强化+解锁职业大师遗物

**转职：** 在营地花费资源解锁新职业，切换后新职业从1级开始。旧职业等级保留。营地“职业训练厅”升级可提高新职业初始等级（最高3级）。

**已讨论设计：**
- 各职业的拉怪方式、基础技能池、终结技风格
- 职业等级解锁表

**待设计项：**
- 各职业完整技能池（6-7个主动技能）的详细效果、升级数据
- 各职业终结技的具体设计（动画、伤害、特效）
- 职业专属被动效果（7级）
- 各职业大师遗物的具体效果

#### 2.2.2 队友（AI角色）
**职业分类：**
- 坦克：誓言骑士、符文战士
- 治疗：光明牧师、药剂师
- 近战输出：刺客、剑术大师
- 远程输出：元素法师、术士
- 策应：吟游诗人、工程师

**AI行为状态：**
- **跟随：** 保持距离，不引怪。若被攻击，边打边把怪带向先锋方向
- **交战：** 坦克护脆皮、输出斩残血、治疗抬血线、策应补位。各司其职
- **爆发：** 按战术暂停编排的序列精确执行技能

**技能：** 每个队友有4个主动技能槽（可从技能池中选择），1个终极技能。技能池在营地训练校场解锁和升级。

**已讨论设计：**
- AI的三种状态转换条件
- 队友在聚怪中的自动掩护行为
- 爆发中的 SkillActionType 承接和技能序列执行

**待设计项：**
- 每个队友职业的技能池（至少6-7个可选技能）
- 队友的数值成长体系（等级？还是固定属性？）
- 队友AI的详细行为树（仇恨建立、技能优先级、站位选择）
- 队友的装备系统（是否可装备？与先锋是否共用装备库？）

#### 2.2.3 敌方单位
**类型：** 近战、远程、施法者、精英、Boss。

**行为：** 巡逻、警戒、追击、攻击、逃跑（特定情况）。

**已讨论设计：** 怪物分布在副本房间中，可被挑衅进入追击状态。

**待设计项：**
- 怪物种类、属性、技能、AI行为树
- 怪物与词缀的互动（词缀如何修改怪物行为/属性）
- 精英怪的特殊机制（光环、召唤、高威胁技能）

### 2.3 地图系统（副本生成与环境）

#### 2.3.1 副本结构
- 每个副本由12-18个房间组成
- 房间类型：怪物房、精英房、随机事件房、休息营地、Boss房
- 房间通过走廊连接，可能包含陷阱
- 单局时长目标：20-30分钟

**已讨论设计：** 预设房间+随机拼接的生成逻辑。

**待设计项：**
- 房间池的设计（每个区域主题下的房间种类、美术风格）
- 房间连接算法（确保动线合理，避免死路）
- 小地图UI和战争迷雾规则

#### 2.3.2 环境物件
**功能分类：**
- 伤害型：爆炸桶、坍塌石柱
- 控制型：粘液池（减速）、束缚藤蔓（定身）
- 聚怪型：窄口、回音水晶（范围挑衅）、升降平台
- 辅助型：魔力泉眼（回蓝）

**已讨论设计：** 环境物件在拉怪/聚怪/击杀中的战略作用，与技能互动（火焰点燃油渍、攻击触发水晶）。

**待设计项：**
- 环境物件的完整列表、生成概率、房间分配规则
- 物件的交互方式（攻击触发、靠近触发、技能触发？）
- 物件的视觉设计和可识别性（让玩家一眼看出能做什么）

#### 2.3.3 词缀系统
**类型：**
- 环境型：魔力乱流（回蓝加速但施法有概率失败）
- 敌人型：狂怒之血（低血量攻击翻倍）
- 资源型：丰饶遗迹（掉落翻倍但怪物数量增加）

**已讨论设计：** 每次副本随机1-3个词缀，影响整体策略。

**待设计项：**
- 词缀库设计（首发15-20个）
- 词缀叠加规则和冲突处理
- 词缀与Boss机制的互动

### 2.4 营地系统（永久成长）
副本外的全部成长和管理内容。

#### 2.4.1 核心建筑
- **招募大厅：** 解锁新队友职业。升级：1级基础，2-3级更多职业变体
- **训练校场：** 解锁/升级队友技能。升级：提高队友等级上限
- **附魔铁砧：** 锻造/强化装备。升级：解锁更高品质锻造
- **炼金工房：** 制作消耗品（药剂、合剂）。升级：解锁更强力配方
- **战略地图桌：** 预览副本词缀/Boss情报。升级：显示信息逐步详细
- **职业训练厅：** 解锁转职。升级：新职业初始等级+1/+2

**已讨论设计：** 营地建筑的升级线和跨职业保留逻辑。

**待设计项：**
- 各建筑的升级消耗（金币、材料）和具体效果数值
- 营地UI/UX设计（主界面、建筑入口、NPC交互）
- 营地NPC的对话和氛围营造

#### 2.4.2 资源管理
- **金币：** 通用货币，锻造、购买消耗品
- **记忆粉尘：** 用于解锁/升级技能（训练校场消耗）
- **特殊材料：** 锻造特定装备、升级建筑

**已讨论设计：** 资源获取来自副本奖励。

**待设计项：**
- 各类资源的详细获取途径和消耗数值表
- 资源存储上限、消耗品携带上限

### 2.5 奖励系统（反馈闭环）

#### 2.5.1 合波评级
**评级标准（单次战斗同时击杀数量）：**
- 普通波次：1-4只，无额外奖励
- 合波：5-8只，银光，经验金币加成
- 史诗合波：9-12只，金光，额外掉落本局消耗品
- 传奇合波：13只以上，虹光，必定额外掉落本局装备/遗物，且强度翻倍

**已讨论设计：** 评级与专注恢复、奖励挂钩。

**待设计项：**
- 击杀计数的具体规则（脱离战斗重置？）
- 连续合波的额外奖励（连击倍率？）
- 评级结算的UI展示和音效反馈

#### 2.5.2 掉落系统
- **装备：** 普通（纯数值）→精良（一条特效）→史诗（强力特效+代价）
- **遗物：** 作用于全队的被动道具，出发前选3个。有“诅咒遗物”子类（强力效果+明显代价）
- **消耗品：** 药剂、合剂、临时Buff卷轴等
- **配方/材料：** 用于营地制作

**已讨论设计：** 掉落受合波评级和词缀影响。

**待设计项：**
- 装备和遗物的完整设计列表
- 稀有度判定逻辑（掉落池、概率表）
- 副本内掉落与营地制作的定位区分

#### 2.5.3 经验与货币结算
- 先锋职业经验：副本通关+合波评级加成
- 队友经验：共享经验池或独立经验？
- 金币/记忆粉尘：基础结算+评级加成

**待设计项：**
- 经验曲线（每级所需经验值）
- 队友成长的具体数值体系
- 结算界面的UI设计

## 三、成长流程与解锁节奏

### 3.1 阶段划分

| 阶段 | 时长 | 解锁系统 | 核心体验 |
|------|------|----------|----------|
| 序章 | 1-2h | 基础移动/挑衅/闪避/终结技 | 第一次拉怪→聚怪→定点→击杀循环 |
| 第一阶段 | 5-8h | 合波评级、完整四人小队、环境物件、掩护系统 | 学会合波概念，利用环境拉怪，呼叫掩护 |
| 第二阶段 | 8-12h | 专注系统、战术暂停、追击、终结技强化 | 学会爆发编排，管理专注资源 |
| 第三阶段 | 10-15h | 遗物系统、装备锻造、转职、职业等级 | 深入构筑，探索不同流派 |
| 第四阶段 | 15-25h | 完整词缀系统、挑战难度、专注扩展 | 应对高难词缀，针对性构筑 |
| 终局 | 无限 | 无尽深渊、全职业满级、赛季 | 极限挑战，构筑优化 |

### 3.2 每个流程环节的广度和深度拓展方向（已明确）
- **拉怪：** 职业差异、装备/遗物改变、环境触发
- **聚怪：** 环境利用、队友掩护、装备/遗物辅助
- **定点：** 环境物件位置、地形利用、队友预先布置
- **击杀：** 战术暂停序列、追击、SkillActionType 承接、终结技
- **掩护：** 队友组合、装备/遗物改变、自动/主动抉择
- **爆发：** 技能池、动作类型组合、装备/遗物影响专注消耗
- **终结技：** 职业差异、强化等级、追击加成

## 五、后续开发建议

1. **垂直切片优先：** 先完成一个先锋职业+2个队友职业+1个区域（12个房间+1个Boss），实现基础循环和爆发系统。这足以验证核心玩法。
2. **核心打磨先行：** 战斗手感（移动、挑衅、闪避的响应）、队友AI的可靠性、战术暂停的操作流畅度——这些是游戏的基石，必须优先打磨到优秀。
3. **内容填充后置：** 更多职业、技能、装备、遗物、词缀、副本区域——在核心玩法验证通过后，按优先级批量填充。
4. **平衡以“有趣”为优先：** 先做有趣的动作类型组合，再做数值平衡。避免为了平衡牺牲构筑多样性。
