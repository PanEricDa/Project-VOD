# 友方仇恨行动节流设计

## 目标

非坦克友方单位在相对仇恨过高时，以连续概率放弃一次共享行动机会，降低普攻和自动技能的频率；不修改现有仇恨累积、目标锁定、移动或技能选择规则。

## 统一入口

`AllyBehaviorStateMachine` 在自动技能与普攻的共同上游执行一次行动许可判断：

```text
战斗目标 → 读取该敌人的本地仇恨表 → 计算相对竞争者仇恨 → 概率暂缓或放行 → 原有技能/普攻链路
```

判定为暂缓时，调用已有共享行动冷却，不请求技能、不请求普攻。单位继续面向、走位和战斗游荡。因为冷却阻止后续帧重复掷骰，普攻与技能自然共享同一概率和节奏。

## 相对仇恨与曲线

相对仇恨定义为：本单位在当前敌人本地仇恨表中的数值，除以除自身外最高的有效仇恨数值。没有其他有效竞争者时返回 0，不进行节流。

单位根节点新增 `threat_action_suppression_at_125`：

- 取值范围 `0.0–0.89`，单位为概率。
- `0.0`：关闭节流；Guardian 等坦克使用。
- 默认 `0.7`：相对仇恨恰为 125% 时有 70% 概率暂缓。

内部曲线在 100% 以下为 0；超过 100% 后指数上升，并向固定 90% 收敛但永远不达到 100%。

```text
p(r) = 0.9 × (1 - exp(-k × (r - 1)))
k = -ln(1 - p125 / 0.9) / 0.25
```

其中 `r` 为相对仇恨，`p125` 为该单位配置值。当前 `p125 = 0.7` 时：112.5% 约 47%、125% 为 70%、150% 约 86%。

## 职责边界

- `EnemyThreatComponent`：只读提供“来源相对最高其他竞争者的仇恨比率”；不决定是否攻击。
- `UnitBase`：保存单位的节流配置；不读取敌方仇恨表。
- `AllyBehaviorStateMachine`：唯一使用该配置执行概率放行，并复用自身共享行动冷却。
- 武器、技能、伤害结算、仇恨结算均不新增专属分支。

未来专注值只需在状态机计算 `p125` 的有效值时施加倍率；上述组件边界和技能/普攻共用入口不变。
