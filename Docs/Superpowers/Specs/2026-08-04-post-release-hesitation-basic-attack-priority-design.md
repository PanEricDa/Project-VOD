# 技能释放后犹豫与普攻优先级设计

## 目标

让 AI 技能成功释放后的随机犹豫只限制该技能下一次释放，不占用普通攻击。共享行动冷却仍由技能释放事件正常启动。

## 状态边界

| 技能状态 | 是否占用普攻 | 说明 |
| --- | --- | --- |
| `QUEUED` | 是 | 已经选定技能并等待进入有效施法范围。 |
| `ACTION_REQUESTED` | 是 | 已请求角色动作，不能插入普攻。 |
| `CASTING` | 是 | 正在播放施法动作。 |
| `POST_RELEASE_HESITATION` | 否 | 已成功释放；只等待此技能开始自身冷却。 |
| `COOLDOWN` / `READY` | 否 | 不存在占用中的技能动作。 |

## 数据流

技能成功释放 → 启动共享行动冷却与技能自身犹豫 → 共享冷却结束后，允许有普攻资格的单位继续普通攻击 → 犹豫结束后才开始该技能的独立冷却。

纯施法策略 `SKILL_ONLY_WITH_BASIC_WHEN_DISABLED` 仍然不使用普攻；本变更只影响允许普攻填充的策略。
